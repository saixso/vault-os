description: Draw the vault as a strategy map (territories, roads from idea to done, unexplored routes) and give the turn report.
---

Read the `vault-map` skill. Then run the flow that fits.

Usage:
- `/vault-map` — rebuild the map page and data in `dashboards/`, then summarize the turn
- `/vault-map report` — the turn report only, nothing written
- `/vault-map names` — rename or join territories in the map config
- `/vault-map claim` — draft a seed idea for an unexplored route, created only on my yes
